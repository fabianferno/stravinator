Six screens, from invite

The full path a runner walks: connect Strava, pick a run, watch it render, save the video. Built to the supplied reference — OLED black, oversized gradient cards, dot-matrix numerals, one lime accent. The numerals are rendered by sampling real glyphs onto a dot grid, so they behave like type rather than an image.
